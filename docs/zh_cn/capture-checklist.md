# 截图采集清单

第一阶段请固定一种 PC 客户端窗口尺寸。建议先使用 16:9 或接近 16:9 的窗口，并保持窗口可见。

## 必需截图

- 正常主界面，所有常用按钮可见。
- 游戏启动后的加载界面。
- 如果存在，服务器登录或点击开始界面。
- 公告弹窗。
- 活动弹窗。
- 通用关闭按钮的不同样式。
- 通用确认按钮的不同样式。
- 主界面的邮件入口。
- 主界面底部的任务入口。
- 邮件页面的全部领取按钮。
- 邮件全部领取后的空状态。
- 每日任务入口。
- 每日任务页面中可领取奖励的状态。
- 奖励确认弹窗。
- 网络错误或重新连接弹窗。

## 模板命名

- `resource/image/home/home_marker.png`
- `resource/image/common/close_button.png`
- `resource/image/reward/mail_entry.png`
- `resource/image/reward/task_entry.png`
- `resource/image/startup/touch_to_start.png`
- `resource/image/hud/home_button.png`

模板应尽量小且稳定。优先截取有辨识度的图标或文字区域，不要直接用整张全屏截图做模板。

更完整的模板落位清单见 `resource/image/template-manifest.json`。

## 记录信息

- 游戏服务器和语言。
- PC 客户端来源、窗口标题和窗口尺寸。
- 使用的 Win32 截图方式和输入方式。
- 哪些弹窗只会每日出现一次，或只会在版本更新后出现。
